SYNTHESIS

What this guide recommends

Where Casey and Andy differ, both positions are retained and a practical recommendation is added. The synthesis is deliberately labelled so it is never mistaken for either author’s published advice.

Strategy-source caveat: Andy explicitly describes his guide as personal Legend/Honestman actual-play notes with a control-oriented style, not a claim that there is one objectively best way to play. Casey likewise revises recommendations as later campaigns expose better options. This merged guide therefore separates mechanics from tested preferences, and preserves disagreements instead of flattening them into false certainty.
Important 1.2.3 caveat: Andy’s SPARK section was written for 1.2.2 and explicitly says it should be mostly ignored after the 1.2.3 SPARK rework. Use the rest of his 1.2.2 class advice as tested guidance, but treat SPARK as version-sensitive.
Honestman: Andy recommends saving normally but not reloading tactical mistakes, reserving saves for bugs/corruption. For a heavily modded first serious LWOTC campaign, this is a sensible safety practice.

Meaning of “comprehensive” here: no substantive gameplay point is intentionally omitted, but anecdotes and prose are paraphrased/clubbed rather than copied line-for-line. If two source paragraphs make the same recommendation, the guide keeps one canonical explanation; if they add different exceptions or disagree, those differences remain.
Known source-conflict policy: when Andy and Casey disagree on an implementation detail that is not conclusively resolved by the stable mechanics reference, the guide displays the disagreement rather than inventing a winner. Bond-training Will recovery is one explicit example. Strategy preferences such as NCE on/off, Technical archetype, Specialist late tree, officer class and some equipment choices are preserved as author/date-specific recommendations.
